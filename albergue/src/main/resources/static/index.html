Interface API do Albergue

Consulte vagas, teste uma reserva e acompanhe reservas existentes.

Consulta de Vagas

A API só informa descrição, quarto, capacidade e valor. Banheiro, beliche e outras características aparecem se estiverem descritos nos dados cadastrados.

Cadastrar Cliente

Cadastre um cliente de teste e use o ID retornado para fazer a reserva. Esta API não implementa autenticação.

Realizar Reserva

Informe um ID de cliente cadastrado acima ou anteriormente. O cartão é apenas uma simulação local: não é enviado nem salvo. Use somente dados fictícios; a API não processa pagamentos.

Vagas selecionadas

Busque a disponibilidade e selecione uma ou mais vagas.
